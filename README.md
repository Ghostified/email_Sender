Email_sender Script  to be used for load testing.

####
This simple script  auto sends 50 emails for a specific interval, in this application , 10 Minutes 


####
Before Running the script
- Create a file name: app_password.py
- In the file app_password.py , add a global variable,  password , to store the value of your email app password. (Eg:  password = 'xxxxxxxxxxx' ) 
-Once the file has completed executing, the count of emails sent by the script will be listed on the email.log file thats autogenerated. 

####
Logs: 
-Once the  script is executed,  an mails.log  file will be generated which logs the count of emails sent.
